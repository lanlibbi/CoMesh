🚀 Was ist der GPU-Pool?

Der GPU-Pool ist eine dezentrale Plattform, auf der die Community GPU-Leistung teilen kann. Als Nutzer kannst du:

  • KI-Modelle nutzen – Chat mit verschiedenen KI-Modellen über unsere API
  • GPU-Leistung teilen – Deine Grafikkarte der Community zur Verfügung stellen und dafür verdienen
  • Credits kaufen – Mit Stripe, PayPal oder Krypto bezahlen
  • Passives Einkommen generieren – Für jede berechnete Anfrage Credits verdienen

👤 Als Nutzer (User)

Du willst KI-Modelle nutzen? Registriere dich, kaufe Credits und starte den Chat. Deine Anfragen werden automatisch an verfügbare GPUs im Pool weitergeleitet.

💻 Als GPU-Anbieter (Provider)

Du hast eine leistungsstarke GPU? Registriere deine Node, installiere den Agenten und lasse die Community deine GPU nutzen. Du verdienst Credits für jede Berechnung.

👤 Schnellstart: Als Nutzer

Schritt 1: Registrierung

  1. Besuche die Startseite
  2. Fülle das Registrierungsformular aus (Name, E-Mail, Passwort)
  3. Alternativ: Login mit bestehendem Account

Schritt 2: Credits kaufen

  1. Klicke auf "Credits"
  2. Wähle einen Paket: Basic (10€), Pro (25€), Max (50€)
  3. Wähle Zahlungsmethode: Stripe, PayPal, oder Krypto
  4. Zahlung abschließen – Credits werden sofort gutgeschrieben

Schritt 3: Chat starten

  1. Gehe zu "Chat"
  2. Wähle ein KI-Modell aus der Liste
  3. Tippe deine Nachricht und drücke Enter
  4. Die Antwort kommt in Echtzeit – gestreamed!
⚠️ Wichtig: Credits werden pro Anfrage abgerechnet. Die Kosten hängen vom Modell und der Token-Anzahl ab. Standard: 1 Credit ≈ 0.001€ pro 1K Tokens.

💻 Schnellstart: Als GPU-Anbieter

Voraussetzungen

  • GPU mit CUDA-Unterstützung (NVIDIA empfohlen)
  • Ollama installiert (ollama.com)
  • Docker (empfohlen) oder Python 3.11+
  • Kein VPN noetig — Portal und Nodes muessen sich nur gegenseitig erreichen koennen (gleiches LAN, DNS-/mDNS-Name empfohlen). Ein Mesh-VPN wie Tailscale ist eine Option, kein Zwang.

Schritt 1: Node registrieren

  1. Registriere dich als User (siehe oben)
  2. Gehe zu "Meine Nodes"
  3. Klicke "Neue Node registrieren"
  4. Gib an:
    • Adresse – optional: Name oder IP, unter der das Portal diese Node erreicht. Leer lassen ist der Normalfall: der Agent traegt seine erkannte Adresse beim ersten Heartbeat selbst ein (DHCP-tauglich).
    • Port – Standard 11435
    • GPU-Modell – z.B. "RTX 3080 10GB"
    • VRAM – z.B. 10240 (in MB)
    • Maximale Jobs – Wie viele parallele Anfragen? (z.B. 2)

Schritt 2: Agent installieren (Docker – empfohlen)

Speichere folgende docker-compose.yml:

version: '3.8'

services:
  gpu-pool-agent:
    image: gpu-pool-node-agent:latest
    container_name: gpu-pool-agent
    restart: unless-stopped
    runtime: nvidia
    environment:
      - PORTAL_URL=http://localhost:8765
      - NODE_ID=DEINE_NODE_ID
      - NODE_API_KEY=DEIN_API_KEY
      - OLLAMA_URL=http://localhost:11434
      - AGENT_PORT=11435
      - HEARTBEAT_SEC=30
    ports:
      - "11435:11435"
    deploy:
      resources:
        reservations:
          devices:
            - driver: nvidia
              count: all
              capabilities: [gpu]

Starte den Agenten:

docker-compose up -d

Schritt 3: Agent ohne Docker (Alternative)

# Abhängigkeiten installieren
pip install fastapi uvicorn httpx psutil pynvml

# Umgebungsvariablen setzen
export PORTAL_URL=http://localhost:8765
export NODE_ID=DEINE_NODE_ID
export NODE_API_KEY=DEIN_API_KEY

# Agent starten

Schritt 4: Node verifizieren

  1. Der Agent sendet automatisch Heartbeats alle 30 Sekunden
  2. Gehe zu "Meine Nodes" – Status sollte "online" sein
  3. Teste die Verbindung: curl http://DEINE_IP:11435/health

🔌 API-Dokumentation

OpenAI-kompatible Endpunkte

Die API ist vollständig OpenAI-kompatibel. Du kannst bestehende Clients verwenden.

Authentifizierung

Alle Requests brauchen einen Authorization: Bearer API_KEY Header.

curl http://localhost:8765/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen2.5-coder:7b",
    "messages": [{"role": "user", "content": "Hallo Welt!"}],
    "stream": true
  }'

Wichtige Endpunkte

MethodeEndpunktBeschreibung
POST/v1/chat/completionsChat mit KI-Modell (streamed)
GET/v1/modelsVerfügbare Modelle listen
GET/v1/meEigenes Profil + Credits
POST/nodes/registerNeue GPU-Node registrieren
POST/nodes/{id}/heartbeatHeartbeat (Agent → Portal)
GET/pool/statusPool-Status + verfügbare GPUs
GET/earningsEarnings-Übersicht

  • 20% – Plattform-Gebühr

🛠️ Troubleshooting

Node zeigt "offline"

  • Prüfe: Läuft der Agent? docker ps | grep gpu-pool
  • Prüfe: erreicht die Node das Portal? curl $PORTAL_URL/net/echo
  • Prüfe: Firewall-Port 11435 offen? ufw allow 11435/tcp
  • Prüfe: Logs docker logs gpu-pool-agent

Ollama nicht erreichbar

  • Ist Ollama gestartet? ollama serve
  • Läuft Ollama auf dem richtigen Port? Standard: 11434
  • Teste: curl http://localhost:11434/api/tags

Keine Credits nach Zahlung

  • Stripe/PayPal im Testmodus? Credits werden trotzdem gutgeschrieben (Demo)
  • Prüfe Zahlungsstatus im Credits-Bereich
  • Kontaktiere Support bei Problemen

Langsame Antworten

  • Pool überlastet? Prüfe Pool-Status
  • Node überlastet? Reduziere max_concurrent_jobs
  • Modell zu groß für GPU? Wähle kleineres Modell

🔒 Sicherheit & Datenschutz

  • Keine öffentlichen Ports – Portal und Agent gehoeren nicht ins offene Internet; ein privates Netz (LAN oder Mesh-VPN) genuegt.
  • API-Keys – Werden sicher in localStorage gespeichert, nicht auf dem Server
  • Passwörter – Gehasht mit bcrypt, nie im Klartext
  • Zahlungen – Alle Zahlungsanbieter sind PCI-DSS konform
  • Daten – Chat-Verlauf bleibt lokal, keine Speicherung auf dem Portal

❓ FAQ

Muss ich meine GPU exklusiv freigeben?

Nein! Der Agent liest nur GPU-Statistiken und leitet Anfragen weiter. Dein System läuft normal weiter – du kannst parallel zocken, rendern, etc.

Werden meine Daten gespeichert?

Chat-Nachrichten werden nicht persistent gespeichert. Nur Metadaten (Token-Anzahl, Kosten) für die Abrechnung.

Kann ich meine Credits auszahlen lassen?

Aktuell noch nicht – Auszahlung über Krypto ist für Phase 2 geplant.

Welche GPUs werden unterstützt?

Alle CUDA-fähigen NVIDIA GPUs. AMD über ROCm ist experimentell. Minimum: 4GB VRAM.

Was kostet es als Provider?

Nichts! Du verdienst Credits. Stromkosten trägst du natürlich selbst – rechnet sich aber durch Earnings.
