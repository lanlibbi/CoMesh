🐳 Node-Agent Setup

Login Chat Credits Pool Meine Nodes Earnings Agent Doku

Bitte einloggen, um den Agent-Setup zu sehen.

Drei Schritte: Node registrieren → Agent bauen → starten. Sobald der Agent den ersten Heartbeat schickt, wird deine GPU im Community-Pool sichtbar.

1) Node registrieren

Auf /nodes ausfüllen. Du bekommst nach dem Registrieren einen agent_api_key.

2) Agent-Image bauen

Klone das Repo (oder kopiere den node-agent/-Ordner) und baue das Image:

cd node-agent
docker build -t gpu-pool-node-agent .

3) Agent starten

Ersetze NODE_ID und NODE_API_KEY mit den Werten aus Schritt 1:


        
Logs checken:


docker logs -f gpu-pool-agent

        
Health check:


curl http://<node-host>:11435/health | jq

      


      

        
4) Verifizieren

        
Sobald dein Node im Pool auftaucht, bist du live. Anfragen werden automatisch an deine GPU geroutet,
        du bekommst 70% der Job-Kosten als Credits auf dein Konto.
