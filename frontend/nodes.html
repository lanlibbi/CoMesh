Was passiert beim Registrieren?

  1. Du bekommst einen agent_api_key — den einmalig anzeigen und sicher speichern.
  2. Du startest den Node-Agent (Docker) auf deiner Maschine mit Node-ID + API-Key.
  3. Der Agent sendet alle 30s einen Heartbeat. Dein Node wird im Community-Pool sichtbar.
  4. Andere User schicken Anfragen — deine GPU verarbeitet sie. Du bekommst 70% der Credits.
