Was ist CoMesh?

What is CoMesh?

CoMesh ist ein gemeinschaftlicher Zugang zu Rechenleistung für KI-Modelle. Wer einen Rechner mit freier Grafikkarte hat, stellt sie dem Pool zur Verfügung. Wer Modelle nutzen will, holt sie sich über eine einzige Schnittstelle, die genauso aussieht wie die von OpenAI — ohne eigene Hardware und ohne Abo.

CoMesh is a shared way to reach computing power for AI models. Whoever owns a machine with a free graphics card offers it to the pool. Whoever wants to use models gets them through a single interface that looks exactly like OpenAI's — no own hardware, no subscription.

iDiese Seite erklärt das Werkzeug für Einsteiger. Sie funktioniert ohne Anmeldung. Zum Mitmachen brauchst du ein Konto — die Freigabe macht ein Administrator.This page explains the tool for newcomers. It works without signing in. To take part you need an account — an administrator approves it.

Für wen ist das gedacht?

Who is this for?
Wenn du Modelle nutzen willst

Wenn du willst, dass Modelle laufen, ohne dass du Hardware kaufst: ein OpenAI-kompatibler Client und ein Schlüssel genügen. Das kann die Weboberfläche sein, ein Programm wie LM Studio oder ein eigenes Skript. Du installierst hier nichts.

If you want models to run

If you want models without buying hardware: an OpenAI-compatible client and a key are enough. That can be the web interface, a program like LM Studio, or your own script. Nothing to install here.

Wenn du eine GPU beisteuern willst

Ein kleiner Agent läuft als Container auf deinem Rechner, meldet die Grafikkarte an den Pool und nimmt Aufträge an. Welche Modelle dein Rechner anbietet, legst du selbst fest. Beides gleichzeitig ist möglich.

If you want to contribute a GPU

A small agent runs as a container on your machine, reports the graphics card to the pool and accepts jobs. You decide which models your machine offers. You can be both at once.

In fünf Schritten loslegen

Get started in five steps
  1. Konto anlegen auf Registrieren. Danach ist das Konto angemeldet, aber noch nicht freigegeben.
  2. Freigabe abwarten. Ein Administrator prüft das Konto. Erst dann sind Modelle erreichbar — Absicht, der Pool gehört der Gemeinschaft.
  3. Schlüssel holen im Profil. Er wird einmal angezeigt; ein neuer Schlüssel macht den alten ungültig.
  4. Ersten Aufruf machen gegen <portal-adresse>:8765/v1. Beispiele stehen darunter.
  5. Verbrauch ansehen unter Mein Verbrauch.
  1. Create an account on Register. Afterwards the account exists but is not approved yet.
  2. Wait for approval. An administrator reviews the account. Only then are models reachable — on purpose: the pool belongs to the community.
  3. Get your key in the profile. It is shown once; a new key invalidates the old one.
  4. Make your first request against <portal-address>:8765/v1. Examples are below.
  5. Watch your usage under My usage.

Dein erster Aufruf

Your first request

Ersetze DEIN-SCHLUESSEL durch den Schlüssel aus dem Profil und PORTAL durch die Adresse des Portals (Port 8765).

Replace YOUR-KEY with the key from your profile and PORTAL with the portal's address (port 8765).

Im Terminal
curl -s http://PORTAL:8765/v1/chat/completions \
  -H "Authorization: Bearer DEIN-SCHLUESSEL" \
  -H "Content-Type: application/json" \
  -d '{"model": "llama3.2", "messages": [{"role": "user", "content": "Sag kurz hallo"}]}'
In the terminal
curl -s http://PORTAL:8765/v1/chat/completions \
  -H "Authorization: Bearer YOUR-KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "llama3.2", "messages": [{"role": "user", "content": "Say hello"}]}'
In Python, mit dem OpenAI-SDK
from openai import OpenAI

client = OpenAI(base_url="http://PORTAL:8765/v1", api_key="DEIN-SCHLUESSEL")

antwort = client.chat.completions.create(
    model="llama3.2",
    messages=[{"role": "user", "content": "Sag kurz hallo"}],
    stream=True,
)
for stueck in antwort:
    print(stueck.choices[0].delta.content or "", end="", flush=True)
In Python, using the OpenAI SDK
from openai import OpenAI

client = OpenAI(base_url="http://PORTAL:8765/v1", api_key="YOUR-KEY")

answer = client.chat.completions.create(
    model="llama3.2",
    messages=[{"role": "user", "content": "Say hello"}],
    stream=True,
)
for chunk in answer:
    print(chunk.choices[0].delta.content or "", end="", flush=True)

Streaming einschalten. Ohne stream=True kann eine lange Antwort an Zwischenschichten hängen bleiben. Mit Streaming kommen die Wörter, während sie entstehen.

Turn streaming on. Without stream=True a long answer can get stuck in intermediate layers. With streaming the words arrive as they are produced.

Welche Modelle gibt es?

Which models are available?
Modelle abfragen
curl -s http://PORTAL:8765/v1/models \
  -H "Authorization: Bearer DEIN-SCHLUESSEL"
List the models
curl -s http://PORTAL:8765/v1/models \
  -H "Authorization: Bearer YOUR-KEY"

Nicht jedes Modell auf jedem Rechner, und manche sind pro Konto zusätzlich freizuschalten. Fehlt eines, obwohl es in der Liste steht, frag den Administrator.

Not every model on every machine, and some need an extra per-account approval. If a model is missing although it appears in the list, ask the administrator.

Was kostet das?

What does it cost?

Kein Geld. Der Verbrauch wird in Credits gemessen, die jedem Konto zugeteilt werden. Wer eine GPU beisteuert, bekommt Credits gutgeschrieben — so trägt sich der Pool selbst. Sind die Credits aufgebraucht, antwortet der Dienst mit einer Fehlermeldung statt still weiterzurechnen. Deinen Stand siehst du unter Mein Verbrauch.

No money. Usage is measured in credits granted to every account. Contributing a GPU earns credits — that is how the pool sustains itself. When credits run out the service answers with an error instead of quietly continuing. Your balance is under My usage.

Wenn etwas nicht geht

When something does not work
  • 401Schlüssel fehlt oder ist ungültig. Vollständig kopiert? Ein neu ausgestellter Schlüssel macht den alten ungültig.
  • 403Das Modell ist nicht freigegeben, oder das Konto ist noch nicht freigeschaltet.
  • 429Zu schnell hintereinander. Kurz warten; die Grenze gilt je Adresse.
  • 502Kein Rechner bietet das Modell gerade an — der Pool besteht aus privaten Rechnern. Später erneut versuchen.
  • 524Zeitüberschreitung. Fast immer fehlendes Streaming: stream=True benutzen.
  • 401Key missing or invalid. Copied completely? A newly issued key invalidates the old one.
  • 403The model is not approved, or the account is not activated yet.
  • 429Too fast in a row. Wait a moment; the limit applies per address.
  • 502No machine is offering that model right now — the pool consists of private machines. Try again later.
  • 524Timeout. Almost always missing streaming: use stream=True.

Gut zu wissen

Good to know
  • Deine Eingaben laufen über einen fremden Rechner. Wer die GPU beisteuert, kann technisch sehen, was durchläuft. Keine Passwörter, keine Personalakten.
  • Keine Verfügbarkeitsgarantie. Fällt der Rechner aus, bekommst du einen Fehler — nicht später eine Antwort.
  • Modelle bleiben kontrollierbar — pro Rechner und pro Konto als Liste.
  • Kein Abo, keine Kreditkarte. Ein Konto lässt sich deaktivieren, der Schlüssel jederzeit erneuern.
  • Your input runs on someone else's machine. Whoever contributes the GPU can technically see what passes through. No passwords, no personnel files.
  • No availability guarantee. If the machine drops out you get an error — not a late answer.
  • Models stay controllable — per machine and per account, as a list.
  • No subscription, no credit card. An account can be deactivated, the key renewed at any time.
