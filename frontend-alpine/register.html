Ein Konto deckt beides ab: die API nutzen und eigene GPUs bereitstellen. Die Rolle legt fest, was freigeschaltet wird — im Profil jederzeit änderbar.

  • →Consumer. API nutzen, keine Hardware bereitstellen. Für Rechner ohne nutzbare GPU.
  • →Provider. Nodes registrieren und Credits verdienen, keine eigenen API-Calls.
  • →Beides. Voller Zugriff — Einbringen und Nutzen gleichzeitig.
