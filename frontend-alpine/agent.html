Node-Agent einrichten

Vier Schritte: Node registrieren, Image bauen, Container starten, im Pool verifizieren. Danach läuft alles über Heartbeats automatisch.

01

Node registrieren

Auf Meine Nodes ausfüllen. Die Antwort enthält den agent_api_key — einmalig sichtbar.

02

Image bauen

Repo klonen (oder den Ordner node-agent/ kopieren) und bauen: 

cd node-agent
docker build -t gpu-pool-node-agent .
03

Container starten

NODE_ID und NODE_API_KEY durch die Werte aus Schritt 1 ersetzen: 


            
Logs verfolgen:

            
docker logs -f gpu-pool-agent

            
Health-Check der Node:

            
curl http://<node-host>:11435/health | jq
